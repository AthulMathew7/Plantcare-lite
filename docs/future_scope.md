# Future scope

The items below are possible future work, not current application
capabilities:

- Improve Cassava model performance and evaluate on independently collected,
  geographically diverse field photographs.
- Add disease classes only alongside suitable verified data, re-training,
  output-order updates, catalog content, and tests.
- Conduct real-device inference, camera, accessibility, and restart testing
  across supported Android versions/devices; add iOS validation if pursued.
- Add reviewed/localized agricultural guidance and additional languages.
- Explore expert review/referral workflows without presenting model results
  as confirmed diagnoses.
- Design, secure, and implement cloud backup/synchronization only if product
  requirements justify a server, authentication/authorization, conflict
  handling, privacy controls, and offline retry behavior.
- Improve documentation-driven license tracking and verify public reuse
  rights before replacing any owner-supplied reference photo.
- Consider weather/environmental context or analytics only with explicit
  privacy, data-quality, and networking requirements.

No item in this list should be read as implemented or scheduled.
